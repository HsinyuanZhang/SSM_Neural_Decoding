# PEFT round-1 评分区段敏感性诊断

本诊断只重算已保存的 `predictions.npz`，不涉及训练、模型选择、heldout 评估或论文复现。所有数值在物理尺度上以 float64 计算；完整精度的分组 R²、SSE、SST 均值和总体标准差见 `results/analysis/peft_round1/cohort_diagnostic.json`。

## 评分区段和完整性检查

| 任务 | allvalid bins | legacy bins | 新增 bins | 新增占 allvalid |

| M1 | 50,591 | 31,971 | 18,620 | 36.804965% |

官方目录内 50 个 fit 均通过以下逐元素检查：`legacy_indices` 是 `allvalid_indices` 的子集；`truth_legacy` 等于 `truth_allvalid` 在这些位置的值；zero 和 ridge 的 legacy 预测也分别等于其 allvalid 预测在这些位置的值。与 `metrics.csv` 的 200 个 allvalid/legacy R² 比较，float64 重算最大绝对差为 `2.6423307986078726e-14`。

`debug_experiment._target_predictions` 的定义说明两个评分区段来自同一批可用 query trial：`legacy` 对每个 trial 使用从 `a+49` 开始的 bins，`allvalid` 使用从 `a` 开始的 bins。因而差集正是这些 trial 的较早 bins，而不是另一份独立测试集。

## 方差加权 R² 的解释

对任一评分区段 (C)，计算

\[
R^2_C=1-\frac{\mathrm{SSE}_C}{\mathrm{SST}_C},\quad
\mathrm{SSE}_C=\sum_{i,d}(y_{id}-\hat y_{id})^2,\quad
\mathrm{SST}_C=\sum_{i,d}(y_{id}-\bar y_{C,d})^2.
\]

因此 allvalid 的 SSE 是两个样本集合 SSE 的和，但其 SST 使用 allvalid 自己的逐输出维均值。改变评分区段会同时改变 SSE 的组成和目标方差；不能按 bins 数对两个评分区段的 R² 做平均来得到 allvalid R²。应直接在 allvalid 数组上重算，或汇总 SSE 后以 allvalid SST 作分母。
