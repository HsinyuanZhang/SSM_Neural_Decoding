## 0. 结论先行（按我认为的优先级）

1. **把 SSM 的"状态即在线回归"这一新范式（DeltaNet / Gated DeltaNet）用到跨 session 校准上。** 具体做法是让校准 trial 直接通过前向递推写进一块"校准记忆"状态，取代 POSSM 依赖梯度的 unit identification。它的数学本质和你们 APST 的闭式岭回归是同一件事，只是换成了递推形式，因此可以和推理共用同一套硬件【推断，最有新意】。
2. **主干改用复数或振荡型的对角 SSM（S4D 复数、LinOSS、Mamba-3 的复数状态）。** 运动皮层有明显的旋转动力学，而 Mamba-2 那种实数标量 A 表达不了旋转。POSSM-S4D 在跨动物 FT 上表现最好，这和上面的判断方向一致，但不能算作证明【推断】。
3. **补上 SSM 专用的参数高效微调手段**（SDLoRA、State-offset Tuning）。每个 session 只调几十到几百个参数，比如每个状态维度的 Δ 缩放或状态偏置。在硬件上这就是一组寄存器【文献 + 推断】。
4. **改造输入端，让它能处理连续时间或事件级数据**（S5 的可变 Δ、Event-SSM）。这样延迟不再受 50 ms chunk 的下限约束，也能容忍丢包和不规则的时间窗。
5. **保证长时间运行稳定**（特征值约束、带状态训练、周期性复位）。POSSM 只用 1 s 的序列训练，而 BCI 要连续跑几个小时。

## 1. SSM 演进脉络，以及每一代对 POSSM 意味着什么

| 代际 | 关键改变 | POSSM 现状 | 可借鉴点 |
|---|---|---|---|
| **S4**（2021） | HiPPO 初始化，可以展开成卷积来训练 | — | — |
| **S4D / DSS**（2022） | 对角化，复数特征值 | POSSM-S4D 用的就是这个【原文 App. B.2】 | 复数特征值能表达振荡 |
| **S5**（2023） | MIMO 结构、并行扫描，**每一步可以用不同的 Δ（支持不规则采样）** | 没有利用这一点 | 事件级、连续时间输入（见 §2.4） |
| **LRU**（2023） | 证明普通线性 RNN 配上合适的初始化和参数化就足够；特征值放在单位圆附近的环形区域 | — | 长时稳定性和初始化（见 §2.5） |
| **Mamba**（2023） | **选择性**：Δ、B、C 都由输入决定 | POSSM-Mamba 的 UI 表现不稳，参数也最多【原文 Table 1, 5】 | 只保留"Δ 选择性"，不必整套照搬 |
| **Mamba-2 / SSD**（2024） | A 退化成每个 head 一个实数标量，可以写成矩阵乘的对偶形式 | — | 对 GPU 友好，但**丢掉了旋转能力**，不适合运动皮层 |
| **线性注意力与 delta rule**：DeltaNet、**Gated DeltaNet**（ICLR 2025）、RWKV-7、Titans 等 | 状态是一个矩阵 S，更新规则相当于对 ‖S·k − v‖² 做一步在线梯度下降（"测试时学习"） | — | **用作前向校准记忆**（见 §2.1） |
| **LinOSS**（ICLR 2025 oral） | 用受迫谐振子作为 SSM，从生物神经振荡得到启发，长序列上稳定 | — | 运动皮层的旋转/振荡动力学（见 §2.2） |
| **Mamba-3**（ICLR 2026） | 梯形离散化（二阶精度）；通过数据相关的 RoPE 实现复数状态；MIMO 结构；状态尺寸减半 | — | 离散化精度、复数状态、更小的状态（见 §2.2, §2.6） |
| **SSM 专用 PEFT**：SDLoRA（ICML 2025）、State-offset Tuning（2025） | LoRA 适合投影层，在 SSM 模块上效果差；对 SSM 应该稀疏地调某些维度，或者调状态偏置 | POSSM 只调 embedding，或者在 embedding 上用 LoRA【原文 §2.3, D.9】 | 每个 session 极少量参数的适配（见 §2.3） |
| **简化 RNN**：minGRU/minLSTM（2024） | 门控只依赖输入、不依赖 h，因此可以并行训练，计算也更省 | POSSM-GRU 用的是标准 GRU | 硬件降本（见 §2.6） |

## 2. 具体优化方向

### 2.1 Delta rule 校准记忆：用前向递推完成跨 session 适配【推断，最推荐】

**动机**
- POSSM 的 UI 要通过冻结的模型做反向传播，跑几百个 epoch【原文 App. C.1】，不能在设备端完成。
- APST 用闭式岭回归（APST 论文 Eq. 1）从带标签的 trial 估计每个 unit 和行为之间的关联，不需要梯度。
- Gated DeltaNet 的状态更新是 `S_t = α_t · S_{t-1}(I − β_t k_t k_tᵀ) + β_t v_t k_tᵀ`，它恰好是对 `‖S k − v‖²` 做一步在线梯度下降。也就是说，**这个状态本身就是一个在线最小二乘求解器**，可以看作 RLS 的一阶近似。

**怎么改**
- 在 POSSM 里加一个"校准记忆"模块：
  - 校准阶段：把带标签 trial 的 `(k = 神经特征 z(t) 或 unit 级特征, v = 行为)` 依次喂进 delta-rule 递推，`S` 逐步学到当前 session 的映射。
  - 解码阶段：冻结 `S`（或者让它以很小的 β 继续缓慢更新），用 `S·k` 作为读出项或残差修正项。
- 训练时用元学习的方式：每个 episode 是"一个 session 的校准段 + 测试段"，让网络学会如何把校准段写进 `S`。这和 APST/SPINT 的"从校准数据生成身份"属于同一类训练范式。
- 还可以做成 unit 级的版本：每个 unit 一个小的 delta-rule 状态，用来积累这个 unit 和行为的关联，作用相当于 APST 的 association profile 的递推版。

**好处**
- 适配只需要前向递推，**硬件上和推理共用同一个 MAC 和状态更新引擎**，不需要反向数据通路。
- 校准数据可以流式进入，不需要先存下所有 trial 再求解，片上存储因此更小。
- 闭环使用时还可以保留一个很小的 β 做慢速在线跟踪，用来应对 session 内部的漂移。这样"离线校准"和"在线自适应"就统一成了一个机制。

**风险**：标签噪声和闭环标签（意图估计）的偏差会直接写进状态；需要和 APST 闭式解做严格对比，看递推版会损失多少精度。

### 2.2 主干动力学：复数、振荡和离散化

- **复数或振荡特征值**：运动皮层群体活动有很强的旋转结构，Churchland 2012 的数据就在 POSSM 的预训练集里【原文 Table 4】。S4D 的复对角、LinOSS 的谐振子、Mamba-3 的复数状态都能直接表达旋转。Mamba-2 风格的实数标量衰减则做不到，只能靠多个 head 去拼。POSSM 的 Table 1 里 S4D 的 FT 在新动物和新数据集上最好（T–CO 0.907，H–CO 0.894），和这个判断方向一致，但不能当作证据【推断】。
  - 实验：在 POSSM-SS 上对比实数对角、复数对角（S4D）、LinOSS 和 Mamba-2 风格，同时看学到的特征值分布是否集中在 1–3 Hz 左右的旋转频率附近。
- **离散化精度**：一个 chunk 50 ms，对于快的模式来说 Δ 相对偏大。Mamba-3 的梯形离散化（二阶）可能比 ZOH 或一阶更准。在 20 ms 和 50 ms 两种 chunk 下对比，看差距是否在 50 ms 时更明显。
- **只保留 Δ 选择性**：完整的 Mamba 选择性（B、C 也随输入变）在 POSSM 里不划算【原文 Table 1, 5】。可以只让 Δ_t 随当前 chunk 的 spike 数或 latent 范数变化。放电剧烈时时间常数变短，静息时变长。代价只是一个标量 MLP 加一次 exp 查表。

### 2.3 SSM 专用的参数高效适配（介于 UI 和 FT 之间）

- SDLoRA（ICML 2025）的结论是：**LoRA 对投影层有效，对 SSM 模块无效**；对 SSM 应该**稀疏地选一部分状态维度来调**。State-offset Tuning 则是给每个时间步的状态加一个可学习的偏置。
- 对 POSSM 的启发【推断】：
  - 除了 unit 和 session embedding，每个 session 再加一个**状态偏置 h_off**（几百维），或者**每维的 Δ 缩放**。从直觉上看，跨天变化有一部分是"整体兴奋度和时间尺度的偏移"，这几个量正好能刻画它。
  - 这类参数仍然可以用 APST 式的闭式方法或前向网络生成，不一定需要梯度。在硬件上它就是一组可写寄存器，几乎没有额外成本。
- 实验：在 FALCON 上对比 UI、UI + h_off、UI + Δ 缩放、LoRA 和 FT，横轴是可调参数量和校准 trial 数。

### 2.4 输入端：从固定 chunk 到连续时间、事件级

- S5 允许每一步用不同的 Δ。Event-SSM（Schöne 等，2024）直接对事件流逐个做 SSM 更新，离散化时用的是实际的时间间隔 Δt。
- POSSM 现在是"在 50 ms chunk 内做交叉注意力，然后做一步递推"，延迟下限就是 chunk 长度。两种改法：
  - **温和改法**：chunk 仍然保留，但递推时的 Δ 用这个 chunk 实际的时长。这样就能支持可变或重叠的窗口、丢包、以及不同采样率的设备。
  - **激进改法**：对每个 spike 做 SSM 更新（Event-SSM 风格），去掉 chunk。但 POSSM 的 App. D.8 显示，把编码器换成 GRU 后效果比交叉注意力差，所以事件级 SSM 能否保住精度要实验验证。可以先只在第一层做事件级更新，后面的层仍按 chunk 运行。
- 硬件意义：事件级更新正好对应 RRAM 或忆阻器那种"事件到达才计算，中间靠器件自然衰减"的异步范式（见 Wei Lu 2026 那篇）。

### 2.5 长时间运行的稳定性

- POSSM 用 1 s 序列训练，测试 trial 长 3–5 倍【原文 §3.1】。但真实 BCI 要连续运行几个小时，长度外推和状态漂移是实际会遇到的问题。
- 可以借鉴的手段：
  - LRU 式参数化：把 |λ| 限制在 [r_min, r_max] 的环形区域内，保证不会发散。
  - **带状态训练**：跨 batch 传递隐状态，做截断 BPTT，让模型见过"很久之前的状态"。
  - 周期性软复位：例如每个 trial 间隙把状态向初始值收缩。
- 硬件意义：定点实现会放大这个问题。|λ| 的上界直接决定了状态寄存器需要多少位宽。

### 2.6 面向硬件的简化

- **实数对角 + block 共享 λ**：这是 Wei Lu 组为了映射到 WOₓ 器件做的约束。它和 §2.2 的"复数更好"有冲突，需要在精度和可实现性之间取舍。折中方案是复数 λ 也只取少数几种共享取值，对应少数几种振荡器。
- **minGRU / 线性 RNN** 替换 GRU：门控和候选状态都只依赖输入，去掉了所有 U·h 这类 256×256 的稠密乘。按 SS 规模（64→256）估算，单步计算量从约 246 K MAC 降到约 33 K MAC，大约是原来的 1/7【估算】。
- **更小的状态**：Mamba-3 用 MIMO 让状态尺寸减半而性能不降。POSSM 的隐状态维度（SS 256、FT 512）可以做一轮扫描，看看能压到多小。
- **量化**：Quamba 等对选择性 SSM 的量化经验（离群值处理、Hadamard 旋转）可以直接复用。

## 3. 建议的实验顺序

| 优先级 | 改动 | 实现成本 | 预期收益 | 评测 |
|---|---|---|---|---|
| 1 | 复数/振荡主干（S4D 复数、LinOSS），对比实数版 | 低 | 精度更高，尤其是跨动物 | POSSM 原数据 + FALCON |
| 2 | SSM 专用适配：状态偏置、Δ 缩放、SDT | 低 | 用极少参数缩小 UI 和 FT 之间的差距 | FALCON，扫校准 trial 数 |
| 3 | Delta-rule 校准记忆（元学习训练），和 APST 闭式解对比 | 中 | 只用前向完成适配，硬件统一 | FALCON M1/M2/H1 + DANDI688 |
| 4 | Δ 选择性、梯形离散化、20 ms vs 50 ms | 低 | 精度和时间尺度自适应 | POSSM 原数据 |
| 5 | 可变 Δ 和事件级输入 | 中到高 | 降低延迟，鲁棒性更好 | 模拟丢包和可变窗口 |
| 6 | 长时稳定性：带状态训练、λ 约束 | 中 | 小时级连续运行 | 拼接多个 trial 做长序列测试 |

第 1、2、4 项都是在 POSSM-SS 上"换一个模块"，适合在复现之后马上做。第 3 项是最有可能成为论文主贡献的方向，并且能和 APST 自然衔接。
